## 📂 Projects

### 01. Student Study Planner — StudyFlow

A modern student study planner built using HTML, CSS, and Vanilla JavaScript.

**Features:**
- Add, complete, and delete study tasks
- Filter tasks by All, Active, and Completed
- Track total, completed, and active tasks
- Visual study progress tracking
- XP and Study Coin reward system
- Level progression
- Completion notifications
- Dark and light mode
- LocalStorage persistence
- Responsive design

**Tech Stack:**
- HTML
- CSS
- JavaScript
- Browser LocalStorage
