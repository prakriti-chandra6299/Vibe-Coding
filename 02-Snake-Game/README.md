# 🐍 Snake Game — Pixel × Neon

A modern, arcade-inspired Snake Game built with HTML, CSS, and vanilla JavaScript. It combines classic snake gameplay with neon visuals, multiple themed worlds, rewards, and game statistics.

## 🎮 Features

- **10 selectable worlds** with different themes, terrain, and obstacles.
- **Three difficulty levels:** Easy, Medium, and Hard.
- **Classic Snake gameplay** with scoring and collision detection.
- **Multiple fruits** with different point values.
- **Mystery gifts** with random rewards.
- **Revive system** using revive tokens.
- **Power mode** with a power meter and automatic steering.
- **Pause and resume** using the interface or Spacebar.
- **Game timer and statistics**, including high score and best time.
- **Responsive controls** for desktop and mobile play.
- **Local storage** to preserve supported game statistics between visits.

## 🕹️ How to Play

1. Open the game and choose a world.
2. Select your preferred difficulty.
3. Press **Start Game**.
4. Guide the snake toward fruit to earn points and grow.
5. Avoid walls, obstacles, and the snake's own body.
6. Collect mystery gifts and use available power-ups or revives strategically.
7. Try to beat your high score!

## 🎛️ Controls

- **Arrow keys / WASD:** Move the snake, where supported by the game.
- **Spacebar:** Pause or resume.
- **On-screen directional controls:** Use on supported mobile layouts.

## 🚀 Run Locally

No backend or package installation is required.

1. Download or clone this repository.
2. Open the `02-Snake-Game` folder.
3. Open `index.html` in a modern web browser.
4. Start playing!

For a more convenient development workflow, open the project in Visual Studio Code and use a local web server extension if desired.

## 🛠️ Built With

- HTML5
- CSS3
- Vanilla JavaScript
- HTML Canvas
- Browser Local Storage

## 💾 Saved Data

The game uses browser `localStorage` for supported statistics and progress. Saved data is specific to the browser and website origin; it is not synchronized across devices.

Clearing browser data may remove saved game progress.
